# OrsoNetwork

> Гибридный сетевой сканер и инструмент инвентаризации для локальных и корпоративных сетей.

OrsoNetwork — open-source инструмент для обнаружения, инвентаризации и анализа сетевых устройств. Проект автоматически находит активные узлы сети, собирает информацию о них из нескольких источников, определяет тип устройств и в дальнейшем будет строить полную карту сети с возможностью детального анализа каждого узла.

---

# Стек и технологии

* **Язык:** Go
* **Поддерживаемые платформы:** Linux (основная), Windows (запланирована)
* **Хранение данных:** SQLite
* **Протоколы обнаружения:**

  * ICMP
  * ARP
  * Reverse DNS
  * NetBIOS
  * TCP
  * SSDP *(в разработке)*
  * mDNS *(в разработке)*
  * SNMP *(в разработке)*
  * **Фронтенд:** SolidJS + Vite
  * **Параллелизм:** goroutines

---

# Ключевые возможности

* Обнаружение активных устройств в подсети.
* Получение MAC-адресов через ARP.
* Определение производителя устройства по MAC-адресу (≈58 000 записей).
* Получение имени устройства через Reverse DNS.
* Определение Windows-хостов через NetBIOS.
* TCP-сканирование распространённых сервисов.
* UDP-обнаружение сервисов.
* Обнаружение устройств через mDNS.
* Определение сервисов через SNMP и SSDP.
* Базовое определение типа устройства (роутер, компьютер и т.д.).
* Единый конвейер обогащения информации о найденных устройствах.
* Подготовка данных для построения топологии сети.
* Веб-интерфейс на SolidJS/Vite.

# Статус разработки

## Реализовано

* Базовая архитектура проекта.
* ICMP Discovery.
* ARP Discovery.
* Reverse DNS Lookup.
* NetBIOS Lookup.
* TCP Port Scanner.
* Определение сервисов открытых TCP-портов.
* Интеграция базы производителей оборудования (MAC → Vendor).
* Базовая идентификация типа устройств.
* Единый процесс обогащения информации о найденных хостах.
* UDP Discovery.
* mDNS Discovery.
* SNMP Probe.
* SSDP Probe.
* Подробная система логирования.
* Построение базовой модели топологии сети.
* Веб-интерфейс на SolidJS/Vite.
* Отображение найденных устройств во фронтенде.

## В разработке

* Более точное определение типа устройств по совокупности признаков.
* Улучшение построения топологии сети.
* Интеграция дополнительных данных UDP/mDNS во фронтенд.
* REST API.
* Параллельные workers для ускорения отдельных этапов сканирования.
* Поддержка Windows без изменения архитектуры проекта.
