
# OrsoNetwork

> Гибридный сетевой сканер и инструмент инвентаризации для крупных сетей (до 5000+ устройств).

OrsoNetwork — open‑source инструмент для инвентаризации и визуализации сети: автоматически обнаруживает устройства, строит топологию и предоставляет возможности глубокой проверки выбранных хостов.

## Стек и технологии

- **Язык:** Go (кроссплатформенный: Linux/OpenSUSE, Windows)
- **Хранение данных:** SQLite (лёгкое хранение результатов сканирования и метаданных)
- **Протоколы обнаружения:** ARP, SNMP (в разработке), mDNS (планируется)
- **Фронтенд:** Vite + SolidJS (визуализация топологии и интерфейс оператора)
- **Параллелизм:** workers для параллельной обработки результатов сканирования

## Ключевые возможности

- **Автоматическое обнаружение устройств** в подсети (ARP‑сканирование).
- **Построение топологии сети** с отображением связей между узлами.
- **Определение вендора и модели устройства** по MAC‑адресу (база ~58 100 записей).
- **Глубокая проверка выбранных хостов** (SNMP‑опрос, сбор характеристик).
- **Масштабируемость** под сети из тысяч устройств за счёт параллельных workers.
- **Кроссплатформенность:** единый код для Linux (OpenSUSE) и Windows.

## Статус разработки

Проект находится в активной разработке. Реализовано:

- Базовая структура проекта и система сборки на Go.
- ARP‑сканер с выводом списка обнаруженных устройств.
- Интеграция базы вендоров (MAC → производитель).
- Начальное построение топологии и связей.

В работе:

- SNMP‑модуль для сбора детальных характеристик устройств.
- Параллельные workers для ускорения сканирования больших подсетей.
- Фронтенд на SolidJS/Vite для визуализации топологии и управления.
